# Лента видео ютуберов на главной странице

Дата: 2026-09-21

## Цель

На главной странице (`index.html`) должна появиться выдвижная панель слева
с подборкой видео нескольких заранее указанных ютуб-каналов: сверху — 2
самых новых видео по всем каналам, ниже — список популярных видео (по
просмотрам) за последний месяц. Цель — держать посетителей сайта в курсе
свежего видеоконтента по игре без необходимости уходить на YouTube вручную.

## Ограничения

- Сайт полностью статический (nginx, без бэкенда и build-шага в самом
  репозитории) — фронтенд не может напрямую дёргать YouTube: RSS-фиды
  каналов блокируются CORS из браузера, а Data API v3 с ключом на клиенте
  либо палит ключ, либо упирается в дневную квоту.
- Список каналов небольшой (3–10 штук) и меняется редко — не нужен
  редактируемый через сайт список, достаточно конфига на сервере.
- VPS (104.128.130.39, FirstByte, Ubuntu 24.04, 1 vCPU / 1 GB RAM) уже
  поднят, на нём есть Node 22 (см. память `anoma-wiki-vps`), обслуживает
  `anoma-wiki.ru` через nginx из `/var/www/anoma`.

## Архитектура

### 1. Сбор данных (сервер, вне текущего деплой-пайплайна репозитория)

Новый скрипт `tools/youtube-feed-fetcher.js` — Node без внешних зависимостей
(только встроенный `https`/`crypto`), по аналогии с существующими
`tools/encrypt-map.js` / `tools/decrypt-map.js`. Коммитится в репозиторий
(как код), но **не** включается в `deploy.yml` (папка `tools` там уже
исключена из синхронизации — см. CLAUDE.md), поэтому на VPS его нужно
разово скопировать и запускать по cron независимо от обычного деплоя
сайта.

- Список каналов (channel ID, отображаемое имя) и `YOUTUBE_API_KEY`
  читаются из переменных окружения / локального конфиг-файла на VPS,
  не из репозитория — ключ никогда не коммитится.
- Для каждого канала:
  1. `channels.list` (part=contentDetails) → id аплоуд-плейлиста.
  2. `playlistItems.list` на этом плейлисте → последние ~20 видео.
  3. `videos.list` (part=snippet,statistics) по их id → заголовок,
     превью, дата публикации, число просмотров.
- Из объединённого списка по всем каналам вычисляются:
  - **Новинки** — 2 видео с максимальным `publishedAt` (по всем каналам).
  - **Популярное** — до 8 видео с максимальным `viewCount` среди тех, что
    опубликованы за последние 30 дней (чтобы старые вирусные ролики не
    держали топ вечно). Пересечение с «новинками» не исключается —
    свежее популярное видео может показаться в обеих секциях.
- Результат пишется как один статический файл `/var/www/anoma/videos.json`
  (перезаписывается атомарно — пишем во временный файл и переименовываем).
- Cron на VPS запускает скрипт раз в час.
- При ошибке запроса к YouTube (сеть, квота, невалидный канал) скрипт
  логирует ошибку и **не перезаписывает** существующий `videos.json` —
  сайт продолжает показывать последний успешно полученный снимок.

Формат `videos.json`:

```json
{
  "generatedAt": "2026-09-21T12:00:00Z",
  "newest": [
    { "id": "abc123", "title": "...", "channel": "...", "thumbnail": "https://i.ytimg.com/vi/abc123/mqdefault.jpg", "publishedAt": "2026-09-21T09:00:00Z", "views": 12345 }
  ],
  "popular": [ /* та же форма, до 8 штук */ ]
}
```

### 2. Фронтенд (`index.html`, `styles.css`)

- **Выдвижная панель** (drawer): `position: fixed`, у левого края,
  `transform: translateX(-100%)` в свёрнутом состоянии, по клику съезжает
  поверх контента (`translateX(0)` с transition) — основной контент
  страницы не сжимается и не смещается.
- **Свёрнутое состояние на десктопе**: узкая вертикальная полоска-язычок у
  левого края экрана с повёрнутым текстом «Видео» (`writing-mode:
  vertical-rl` или эквивалент через transform) и иконкой; всегда видна,
  кликабельна, открывает панель.
- **Мобильный триггер**: отдельная кнопка-иконка в `.site-nav` (рядом с
  существующими ссылками) — на маленьких экранах вертикальный язычок
  неудобен, поэтому открытие идёт через обычную кнопку в шапке.
- **Содержимое панели**:
  - Секция «Новинки» — 2 карточки сверху (превью, заголовок, канал, дата).
  - Секция «Популярное» — список карточек ниже (превью, заголовок, канал,
    отформатированное число просмотров, дата), отсортирован по убыванию
    просмотров.
  - Каждая карточка — целиком `<a href="https://www.youtube.com/watch?v=<id>" target="_blank" rel="noopener">`, никакого встроенного плеера.
- **Загрузка данных**: один `fetch('/videos.json')` при загрузке страницы
  (тот же паттерн, что уже используется в инлайн-скрипте для
  `PLAYTESTS` — те же вспомогательные функции стиля `esc()`,
  ручной рендер через `innerHTML`).
- **Деградация при отказе**: если `fetch` упал (сеть, файл ещё не создан,
  VPS недоступен) — язычок и мобильная кнопка не отображаются вовсе,
  никакой ошибки пользователю не показывается.

### Вне рамок этой задачи

- Панель добавляется только на `index.html` (не на `/art-calc`).
- Никакой пагинации/бесконечной подгрузки — фиксированные 2 + до 8 видео
  за снимок.
- Никакого встроенного плеера — только переход на YouTube.
- Редактирование списка каналов через сайт/репозиторий не предусмотрено.

## Тестирование

- Локально: подложить тестовый `videos.json` в корень (`python3 -m
  http.server` — см. CLAUDE.md "Local preview") и проверить рендер панели,
  открытие/закрытие, мобильную кнопку через resize окна браузера.
- На VPS: прогнать `tools/youtube-feed-fetcher.js` вручную один раз,
  проверить валидность полученного `videos.json`, затем поставить cron.
- Проверить деградацию: временно переименовать/удалить `videos.json` на
  локальном сервере и убедиться, что язычок/кнопка пропадают без ошибок в
  консоли.
