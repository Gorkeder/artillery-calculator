# Кланы, роли, отряды и тактическая карта — дизайн

Дата: 2026-10-13. Статус: согласовано. Этап 1 реализован и выкачен; этап 2 (планы, опрос, карандаш, ластик) реализован в ветке `clans-tactics-stage2`; этап 3 ждёт плана.

Продолжает спеки [карты](2026-10-11-interactive-map-editor-design.md),
[аккаунтов](2026-10-11-user-accounts-design.md) и [личных меток](2026-10-11-personal-marks-design.md).

## Цель

Игроки объединяются в **кланы**. Внутри клана есть **роли с правами, как в Discord**, и **отряды**.
На карте `/map` появляется режим **«Тактика»**: общий слой клана, на котором лидер и доверенные лица
рисуют (прежде всего карандашом), кто куда идёт. Каждый рисунок привязан к отряду и окрашен в его цвет.
Участники клана видят изменения примерно через 15 секунд без перезагрузки.

**Критерий успеха:** лидер рисует карандашом путь «Альфы» на активном плане, и в течение ~15 с все
участники клана видят его у себя. Пустые проверки обновлений почти не нагружают сервер (`304`).

## Решения (согласовано)

| Вопрос | Решение |
|--------|---------|
| Где тактика | Режим внутри `/map` (кнопка «Тактика»), а не отдельная страница |
| Обновления | Опрос раз в 15 с с `ETag`/`304`; пауза при скрытой вкладке |
| Вступление | Ссылка-приглашение **и** приглашение по логину с подтверждением |
| Кланов на игрока | Один |
| Право рисовать | У роли: «все отряды» или список конкретных отрядов |
| Кто что видит | Все участники видят рисунки всех отрядов; фильтр по отрядам |
| Инструменты | Главный — карандаш (от руки); дополнительно стрелка, зона, метка, текст, ластик |
| Жизнь рисунков | Несколько планов на клан; один активный на каждую карту |
| Телефон | Только просмотр и фильтр; рисование только на ПК |
| Публичность | Публичный каталог `/clans` и профиль клана со списком участников |
| Эмблема | Своя картинка (загрузка), админ может сбросить |
| Админ сайта | Видит тактику всех кланов (чтение + удаление при нарушениях), не рисует |
| Отряды участника | Участник может быть в нескольких отрядах (основной, запасной и т. п.) |
| Ссылки на планы | Случайный `public_id` (12 символов), задел под просмотр без аккаунта |
| Лимиты | 50 участников, 10 отрядов, 10 ролей (без `@everyone`), 25 планов на клан; 500 рисунков на план, 2000 точек на штрих |

Не входит в эту версию: просмотр плана по ссылке без аккаунта, союзы кланов, несколько кланов на игрока,
рисование на телефоне, отмена/повтор (Ctrl+Z), письма о приглашениях, обновление чаще 15 с (WebSocket/SSE).

## Данные (миграция 6)

```
clans              id, tag UNIQUE (2–5 символов), name UNIQUE, description, emblem_path,
                   owner_id → users, created_at
clan_members       clan_id → clans, user_id → users UNIQUE, joined_at
clan_roles         id, clan_id, name, color, position, perms (битовая маска),
                   draw_all_squads (0/1), is_everyone (0/1)
clan_role_squads   role_id → clan_roles, squad_id → clan_squads   (PK обоих)
clan_member_roles  clan_id, user_id, role_id                       (PK user_id+role_id)
clan_squads        id, clan_id, name, color, position
clan_squad_members squad_id, user_id                               (PK обоих)
clan_invites       token_hash PK, clan_id, created_by, created_at, expires_at (NULL = бессрочно),
                   max_uses (NULL = без лимита), uses, revoked
clan_invitations   id, clan_id, user_id, invited_by, created_at   (UNIQUE clan_id+user_id)
tactic_plans       id, public_id UNIQUE, clan_id, map_id → maps, title, is_active,
                   version, updated_at, updated_by
tactic_items       id, plan_id → tactic_plans, squad_id → clan_squads (NULL = общий),
                   kind ('pencil'|'arrow'|'zone'|'marker'|'text'), geometry (JSON),
                   width (1..3), icon, label, author_id → users, created_at, updated_at
users              + clans_blocked INTEGER NOT NULL DEFAULT 0
```

Правила:
- Все внешние ключи на клан — `ON DELETE CASCADE`. Удаление пользователя убирает его из клана;
  если он был лидером — см. «Передача лидерства».
- `tactic_items.squad_id` — `ON DELETE SET NULL`: рисунки удалённого отряда становятся общими.
- Координаты — доли 0..1 от картинки карты, как у `features` и `user_marks`.
- Роль `@everyone` создаётся вместе с кланом (`is_everyone = 1`, всегда самая низкая позиция,
  по умолчанию только `tactics_view`). Её нельзя удалить, переименовать или выдать вручную —
  она неявно есть у каждого участника.
- Любое изменение плана или его рисунков увеличивает `tactic_plans.version` в той же транзакции.
- Активный план — не больше одного на пару (`clan_id`, `map_id`); активация снимает флаг с прежнего.
- Удаление клана удаляет и файл эмблемы.
- `public_id` — 12 символов base62 из `crypto.randomBytes`.
- Токен приглашения хранится только как хэш (как в `tokens.js`).

### Геометрия рисунков

| kind | geometry | Прочее |
|------|----------|--------|
| pencil | `[[x,y], ...]` 2..2000 точек | `width` |
| arrow | `[[x,y], ...]` 2..50 точек, стрелка на последней | `width` |
| zone | `[[x,y], ...]` 3..200 точек (замкнутый контур) | `label` необязателен |
| marker | `[x,y]` | `icon` из встроенного набора, `label` ≤ 60 |
| text | `[x,y]` | `label` 1..120 |

Иконки меток: сбор, атака, оборона, враг, артиллерия, снайпер, опасность, вопрос.

## Права

### Флаги ролей

| Флаг | Что даёт |
|------|----------|
| `tactics_view` | видеть планы и тактику |
| `tactics_draw` | рисовать и править для своих отрядов (`draw_all_squads` или `clan_role_squads`) |
| `plans_manage` | создавать, переименовывать, удалять планы, делать активным, очищать |
| `squads_manage` | создавать, удалять, переименовывать отряды, распределять людей по отрядам |
| `invite` | ссылки-приглашения и приглашения по логину |
| `kick` | исключать участников ниже себя |
| `roles_manage` | создавать и править роли ниже своей, выдавать и снимать их у участников ниже себя |
| `clan_settings` | название, тег, описание, эмблема |

### Контекст участника

Считается одним запросом при каждом обращении (снятая роль действует сразу):
- `perms` = объединение масок всех ролей участника, включая `@everyone`;
- `drawSquads` = «все», если хоть одна роль с `tactics_draw` имеет `draw_all_squads`, иначе объединение
  `clan_role_squads` ролей с `tactics_draw`;
- `top` = наибольшая позиция среди ролей участника;
- `isOwner` — лидер: все права, вне иерархии.

### Иерархия (как в Discord)

- Нельзя создать, изменить, переместить или выдать роль с позицией ≥ своей `top`.
- Нельзя включить в роли флаг, которого нет у себя (защита от «дал себе всё»).
- Нельзя исключить участника, поменять ему роли или отряды, если его `top` ≥ своей.
- Лидер всё может; лидерство передаёт только сам лидер; клан удаляет лидер или админ сайта.

### Рисование

- Создать рисунок для отряда X: `tactics_draw` и X ∈ `drawSquads`. Общий рисунок (без отряда) — только
  при «все отряды».
- Изменить или удалить чужой рисунок — по тем же правилам, что создать (ластик командира Альфы стирает
  только рисунки Альфы). Свой рисунок автор всегда может удалить, пока состоит в клане.
- Очистить план целиком — `plans_manage`; очистить отряд в плане — `plans_manage` или рисование для этого отряда.

### Админ сайта

Читает любой клан и план. Может удалить план или рисунок, переименовать клан, сбросить эмблему и описание,
удалить клан, поставить пользователю `clans_blocked`. Рисовать в чужом клане не может.

### Где живёт логика

Новый модуль `server/clan-permissions.js`: `memberContext(db, clanId, userId)` и чистая функция
`clanCan(ctx, action, resource)`. Покрывается тестами так же, как `permissions.js`. `permissions.js`
получает только действие `clan:create` (почта подтверждена, не в клане, нет `clans_blocked`).

## API

Всё под `/api/`, сессии и формат ошибок `{error}` — как сейчас. Любой `:id` проверяется на принадлежность
клану пользователя; чужое отвечает 404.

**Публично:**
- `GET /clans?q=` — каталог: тег, название, эмблема, число участников.
- `GET /clans/:tag` — профиль: описание, лидер, участники с именами и цветами ролей.

**Мой клан:**
- `GET /my/clan` — мой клан, мои права, `drawSquads`, роли, отряды, участники; для неучастника — `null`
  и входящие приглашения.
- `POST /clans` — создать; создатель становится лидером.
- `PATCH /clans/:id`; `POST|DELETE /clans/:id/emblem` (тип проверяется, сжатие, ≤ 200 КБ; как фото объектов).
- `DELETE /clans/:id`; `POST /clans/:id/transfer` `{userId}`.
- `POST /clans/:id/leave` (лидер не может выйти, не передав лидерство или не удалив клан);
  `DELETE /clans/:id/members/:userId`.

**Роли и отряды:**
- `GET|POST /clans/:id/roles`, `PATCH|DELETE /clans/:id/roles/:roleId`, `PUT /clans/:id/roles/order`.
- `GET|POST /clans/:id/squads`, `PATCH|DELETE /clans/:id/squads/:squadId`, `PUT /clans/:id/squads/order`.
- `PUT /clans/:id/members/:userId` `{roles: [], squads: []}` — меняет только то, на что хватает прав.

**Приглашения:**
- `POST /clans/:id/invites` `{ttl: '1d'|'7d'|null, maxUses: number|null}` → ссылка `/clan/join/<токен>`;
  `GET /clans/:id/invites`; `DELETE /clans/:id/invites/:inviteId`.
- `POST /clans/join/:token` — вступить.
- `POST /clans/:id/invitations` `{login}`; `DELETE` — отозвать;
  `POST /invitations/:id/accept|decline`.
- Вступление (любым способом) проверяет: игрок не в клане, клан не заполнен (50).

**Тактика:**
- `GET /clans/:id/plans?map=` — список планов.
- `POST /clans/:id/plans` `{mapId, title}`; `PATCH /plans/:publicId`; `DELETE /plans/:publicId`;
  `POST /plans/:publicId/activate`; `POST /plans/:publicId/clear?squad=`.
- `GET /plans/:publicId` — план с рисунками, `ETag: "v<version>"`. Если `If-None-Match` совпал,
  ответ `304` после одной выборки плана по ключу и проверки членства, без загрузки рисунков.
- `POST /plans/:publicId/items`; `PATCH|DELETE /items/:id`. Ответ содержит новую `version`.

**Защита:** лимитер тактики — не больше 60 правок в минуту на пользователя (штрих карандаша = один запрос
при отпускании мыши). Тексты проверяются через `validate.js`. Админу сайта — переключатель «Клан» и
те же `GET`, плюс удаление.

**Письма о приглашениях не отправляются:** приглашение видно в `/clan`, `/account` и в шапке.

## Интерфейс

### Страница `/clan` (`clan.html`, `clan.js`, `clan.css`, стиль как у `/account`)

- **Не в клане:** входящие приглашения (принять / отклонить), «Создать клан», ссылка на каталог.
- **В клане**, вкладки (без нужных прав вкладка скрыта):
  - **Обзор** — эмблема, описание, «Открыть тактику», «Выйти из клана»;
  - **Участники** — роли и отряды каждого, кнопки «Роли», «Отряды», «Исключить» по правам;
  - **Роли** — список с перетаскиванием порядка, редактор: имя, цвет, переключатели прав,
    «Рисует для: все отряды / выбранные»;
  - **Отряды** — имя, цвет, состав;
  - **Приглашения** — активные ссылки (срок, использования, отозвать), ожидающие по логину;
  - **Настройки** — название, тег, описание, эмблема, передача лидерства, удаление клана.
- `/clans` — каталог с поиском; `/clans/<TAG>` — публичный профиль.
- `/clan/join/<токен>` — экран вступления; гость уходит на вход и возвращается обратно.
- Шапка `/map` и главной: тег клана рядом с ником, счётчик входящих приглашений.
- nginx: `location`-правила для `/clan`, `/clans`, `/clans/…`, `/clan/join/…` (см. `RELEASE.md`).

### Режим «Тактика» на `/map`

Файлы: `map-tactics.js` (просмотр, опрос, фильтр, панель планов) и `map-tactics-editor.js`
(инструменты, только ПК), подключаются так же, как `map-marks*.js`.

- Кнопка «Тактика» видна участникам клана с `tactics_view` и админу. В режиме тактики общие объекты и
  личные метки скрыты; панель: выбор плана (★ активный), фильтр отрядов (чекбоксы с цветами, «только мои»),
  легенда, индикатор «обновлено N с назад» / «нет связи».
- Ссылка `/map?tactics=1&plan=<publicId>` открывает нужный план (и его карту); без `plan` открывается
  активный план текущей карты.
- **ПК, есть право рисовать:** инструменты Карандаш (по умолчанию) · Стрелка · Зона · Метка · Текст · Ластик;
  выбор «рисую за: [отряд ▾]» (только разрешённые); толщина 3 уровня; клавиши `P` карандаш, `E` ластик,
  `1–9` отряд, `Esc` отмена. Карандаш рисует при зажатой левой кнопке; перетаскивание карты в режиме
  карандаша — правой кнопкой или пробел + мышь. Штрих упрощается (Дуглас–Пекер, `map-geo.js`) и отправляется
  при отпускании; до ответа сервера показан сразу.
- Цвет рисунка — цвет отряда; общий рисунок — белый/цвет клана.
- **Телефон:** только просмотр, выбор плана и фильтр.
- **Админ:** переключатель «Клан: [▾]», без инструментов рисования, с удалением рисунков и планов.

### Синхронизация

Таймер 15 с; при `document.hidden` опрос останавливается, при возврате на вкладку — немедленный запрос.
Свои правки применяются локально сразу, а `version` из ответа сервера обновляет `ETag` клиента.
При ответе с новой версией план перерисовывается целиком (рисунки сопоставляются по `id`).

## Ошибки

- Права потеряны (роль снята, исключён): запрос даёт 403/404 → режим тактики закрывается с сообщением,
  данные `/my/clan` перечитываются.
- План удалён: «План удалён» → переход на активный план карты (или пустое состояние «Нет планов»).
- Нет сети при отправке штриха: штрих остаётся полупрозрачным с кнопкой «Повторить»; индикатор «нет связи».
- Превышены лимиты (планы, рисунки, участники, точки): 400/409 с понятным текстом.
- Клан удалён, пока открыт `/clan`: перечитать состояние, показать «Клан удалён».

## Тесты (`node --test`)

- `clan-permissions`: объединение ролей, `@everyone`, `drawSquads`, иерархия (позиции, нельзя выдать
  отсутствующий флаг), лидер, админ сайта.
- Маршруты кланов: создание (почта, один клан, `clans_blocked`), уникальность тега и имени, лимиты,
  передача лидерства, выход, исключение, удаление с эмблемой.
- Роли и отряды: CRUD, порядок, назначение участнику, удаление отряда → рисунки становятся общими.
- Приглашения: срок, лимит использований, отзыв, заполненный клан, игрок уже в клане, приглашение по логину.
- Тактика: права по отрядам, общий рисунок, ластик чужого, `ETag`/`304`, рост `version`, один активный
  план на карту, лимиты, чужой клан → 404, админ читает и удаляет, но не создаёт.
- `map-geo.js`: упрощение штриха (Дуглас–Пекер).

## Этапы реализации

Каждый этап выкатывается отдельно.

1. **Кланы, роли, отряды, приглашения:** миграция 6, `clan-permissions.js`, `routes/clans.js`, страница
   `/clan`, каталог и профиль, тег в шапке, nginx.
2. **Тактика:** планы, просмотр с опросом и фильтром, карандаш и ластик, `routes/tactics.js`.
3. **Остальное:** стрелка, зона, метка, текст; админский просмотр кланов и тактики; абзац в `/privacy`
   (кланы публичны, администрация видит тактику); обновление `CLAUDE.md` и `RELEASE.md`.
