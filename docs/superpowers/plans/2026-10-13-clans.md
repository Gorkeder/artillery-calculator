# Кланы, роли, отряды и приглашения (этап 1) — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Игроки создают кланы, приглашают людей (ссылкой и по логину), настраивают роли с правами в стиле Discord и отряды; у кланов есть публичный каталог и профиль.

**Architecture:** Новая миграция 6 в `server/db.js`. Логика прав клана — чистые функции в `server/clan-permissions.js` (контекст участника считается из БД на каждый запрос). SQL кланов — в `server/clan-repo.js`, проверки ввода — в `server/clan-validate.js`, общие хелперы маршрутов — в `server/clan-http.js`. Маршруты разнесены по трём файлам: `routes/clans.js` (клан, участие, эмблема), `routes/clan-roles.js` (роли, отряды, назначения), `routes/clan-invites.js` (ссылки и приглашения по логину). Все изменяющие запросы возвращают полное тело `GET /api/my/clan`, чтобы фронтенд просто перерисовывался. Фронтенд — одна страница `clan.html` на пути `/clan`, `/clans`, `/clans/<TAG>`, `/clan/join/<токен>`; вкладки управления — в отдельных файлах.

**Tech Stack:** Node 22+ (`node:http`, `node:sqlite`, `node:test`), без npm-зависимостей; фронтенд — ES5 без сборки, хелперы `window.MapApi` и `window.h` из `map-common.js`.

**Spec:** `docs/superpowers/specs/2026-10-13-clans-tactics-design.md` (этот план — этап 1 «Кланы, роли, отряды, приглашения»; тактика — этапы 2 и 3, отдельные планы).

## Global Constraints

- Node 22+, никаких npm-зависимостей; тесты: `node --test server/test/*.test.js tools/*.test.js`.
- Один клан на игрока (`clan_members.user_id UNIQUE`).
- Лимиты: 50 участников, 10 отрядов, 10 ролей (без `@everyone`) на клан. Дополнительно: 20 активных ссылок, 50 ожидающих приглашений по логину.
- Тег: 2–5 букв (латиница/кириллица) или цифр; название 3–40 символов; описание до 500; имена ролей и отрядов 1–30.
- Тег и название уникальны без учёта регистра и `ё`/`е` (ключ считается в JS: SQLite `lower()` не понимает кириллицу).
- Создать клан: почта подтверждена, нет `users.clans_blocked`, не состоит в клане.
- Права ролей — 8 флагов: `tactics_view, tactics_draw, plans_manage, squads_manage, invite, kick, roles_manage, clan_settings`. У `@everyone` по умолчанию только `tactics_view`.
- Иерархия: нельзя трогать роль с позицией ≥ своей; нельзя включить или выключить флаг, которого нет у себя; нельзя действовать над участником, чья старшая роль ≥ твоей; лидер вне иерархии.
- Админ сайта: переименовывает и правит описание любого клана, сбрасывает эмблему, удаляет клан, ставит `clans_blocked`. Внутрь чужого клана (роли, участники) не вмешивается.
- Токен ссылки-приглашения хранится только как SHA-256 хэш; ссылка показывается один раз при создании.
- Эмблема: PNG/JPEG/WebP по сигнатуре, ≤ 200 КБ, стороны ≤ 1024 px. Пересжатия нет (в проекте нет библиотеки картинок) — это сознательное упрощение относительно спека.
- Параметры маршрутов — только строчные буквы (`:id`, `:uid`, `:rid`, `:sid`, `:iid`, `:tag`, `:token`): роутер `server/app.js` ловит ключ регексом `:([a-z]+)`.
- Все ответы и ошибки — JSON `{error}` как сейчас; коды ошибок для фронтенда — snake_case (`tag_taken`, `clan_full`, …).
- Русский текст интерфейса; ширина 375 px без горизонтальной прокрутки.

## Review Focus

1. **Два одновременных вступления/создания одним игроком** — второе должно получить 409, а не 500: проверки членства выполняются после последнего `await` (после чтения тела), вставка в той же синхронной транзакции. Тест — Task 4 (параллельные `POST /api/clans`) и Task 8 (параллельные вступления по ссылке).
2. **Вступление в заполненный клан** через ссылку, приглашение по логину и после того, как ссылка исчерпала лимит, — `clan_full` / `invite_invalid`. Тест — Task 8.
3. **Офицер пытается выдать себе или другому роль с правами, которых у него нет**, или поднять свою роль выше — 403. Тест — Task 7.
4. **Кириллический тег в URL** (`/api/clans/%D0%92%D0%9E%D0%9B`) и разный регистр — профиль находится. Тест — Task 4.
5. **Удаление клана, участника или отряда оставляет хвосты** (роли участника, членство в отрядах, файл эмблемы, ожидающие приглашения) — каскады и удаление файла. Тест — Task 1, Task 5, Task 6.

```js
test('migration 6 upgrades a version 5 database and keeps users', () => {
  const db = new DatabaseSync(':memory:');
  db.exec(SCHEMA);
```

```js
'use strict';

const test = require('node:test');
const assert = require('node:assert/strict');
const { openDb } = require('../db');
const P = require('../clan-permissions');

const { PERMS } = P;

function fixture() {
  const db = openDb(':memory:');
  const user = (login) => Number(db.prepare("INSERT INTO users (login, password_hash) VALUES (?, 'x')").run(login).lastInsertRowid);
  const owner = user('owner');
  const lead = user('lead');
  const lead2 = user('lead2');
  const cmd = user('cmd');
  const grunt = user('grunt');
  const outsider = user('outsider');
  const clanId = Number(db.prepare(
    "INSERT INTO clans (tag, tag_key, name, name_key, owner_id) VALUES ('ALF', 'alf', 'Alpha', 'alpha', ?)",
  ).run(owner).lastInsertRowid);
  for (const u of [owner, lead, lead2, cmd, grunt]) {
    db.prepare('INSERT INTO clan_members (clan_id, user_id) VALUES (?, ?)').run(clanId, u);
  }
  const role = (name, position, perms, drawAll = 0, everyone = 0) => Number(db.prepare(
    'INSERT INTO clan_roles (clan_id, name, position, perms, draw_all_squads, is_everyone) VALUES (?, ?, ?, ?, ?, ?)',
  ).run(clanId, name, position, perms, drawAll, everyone).lastInsertRowid);
  const squad = (name) => Number(db.prepare(
    "INSERT INTO clan_squads (clan_id, name, color) VALUES (?, ?, '#ffffff')",
  ).run(clanId, name).lastInsertRowid);
  role('@everyone', 0, PERMS.tactics_view, 0, 1);
  const alpha = squad('Alpha');
  const bravo = squad('Bravo');
  const officer = role('Officer', 2, PERMS.tactics_draw | PERMS.kick | PERMS.roles_manage, 1);
  const alphaCmd = role('Alpha cmd', 1, PERMS.tactics_draw);
  db.prepare('INSERT INTO clan_role_squads (role_id, squad_id) VALUES (?, ?)').run(alphaCmd, alpha);
  const give = (u, r) => db.prepare('INSERT INTO clan_member_roles (user_id, role_id) VALUES (?, ?)').run(u, r);
  give(lead, officer);
  give(lead, alphaCmd);
  give(lead2, officer);
  give(cmd, alphaCmd);
  const ctx = (u) => P.memberContext(db, u);
  return { db, clanId, owner, lead, lead2, cmd, grunt, outsider, officer, alphaCmd, alpha, bravo, ctx };
}

test('perm names round-trip and unknown names are rejected', () => {
  assert.deepEqual(P.permsToNames(PERMS.kick | PERMS.invite), ['invite', 'kick']);
  assert.equal(P.namesToPerms(['invite', 'kick']), PERMS.kick | PERMS.invite);
  assert.equal(P.namesToPerms([]), 0);
  assert.equal(P.namesToPerms(['fly']), null);
  assert.equal(P.namesToPerms('kick'), null);
  assert.equal(P.ALL_PERMS, 255);
});

test('memberContext unions roles, includes @everyone and resolves draw squads', () => {
  const f = fixture();
  const o = f.ctx(f.owner);
  assert.deepEqual([o.isOwner, o.perms, o.top, o.drawSquads], [true, 255, Infinity, 'all']);
  const l = f.ctx(f.lead);
  assert.equal(l.isOwner, false);
  assert.equal(l.perms, PERMS.tactics_view | PERMS.tactics_draw | PERMS.kick | PERMS.roles_manage);
  assert.equal(l.top, 2);
  assert.equal(l.drawSquads, 'all', 'one role with draw_all_squads is enough');

  assert.equal(c.top, 1);

test('hierarchy: owner outranks all, equal rank does not outrank, nobody outranks the owner', () => {
  const f = fixture();
  assert.equal(P.outranks(f.ctx(f.owner), f.ctx(f.lead)), true);
```

```js
'use strict';

// Clan permissions are role flags (like Discord). The clan owner holds every flag and stands above
// every role. Everything here except memberContext is pure, so routes and tests share the same rules.
const PERMS = {
  tactics_view: 1,
  tactics_draw: 2,
  plans_manage: 4,
  squads_manage: 8,
  invite: 16,
  kick: 32,
  roles_manage: 64,
  clan_settings: 128,
};
const PERM_NAMES = Object.keys(PERMS);
const ALL_PERMS = 255;
const EVERYONE_DEFAULT = PERMS.tactics_view;

function permsToNames(mask) {
  return PERM_NAMES.filter((n) => (mask & PERMS[n]) !== 0);
}

function namesToPerms(names) {
  if (!Array.isArray(names)) return null;
  let mask = 0;
  for (const n of names) {
    if (typeof n !== 'string' || !Object.prototype.hasOwnProperty.call(PERMS, n)) return null;
    mask |= PERMS[n];
  }
  return mask;
}

// One clan per player, so the context is found by the user alone. Read on every request:
// a removed role stops working immediately.
function memberContext(db, userId) {
  const m = db
    .prepare('SELECT m.clan_id, c.owner_id FROM clan_members m JOIN clans c ON c.id = m.clan_id WHERE m.user_id = ?')
    .get(userId);
  if (!m) return null;
  if (m.owner_id === userId) {
    return { clanId: m.clan_id, userId, isOwner: true, perms: ALL_PERMS, top: Infinity, drawSquads: 'all' };
  }
  const roles = db
    .prepare(
      `SELECT id, position, perms, draw_all_squads FROM clan_roles
       WHERE clan_id = ? AND (is_everyone = 1 OR id IN (SELECT role_id FROM clan_member_roles WHERE user_id = ?))`,
    )
    .all(m.clan_id, userId);
  let perms = 0;
  let top = 0;
  let drawAll = false;
  const drawRoleIds = [];
  for (const r of roles) {
    perms |= r.perms;
    if (r.position > top) top = r.position;
    if (r.perms & PERMS.tactics_draw) {
      if (r.draw_all_squads) drawAll = true;
      else drawRoleIds.push(r.id);
    }
  }
  let drawSquads = 'all';
  if (!drawAll) {
    drawSquads = drawRoleIds.length
      ? db
        .prepare(
          `SELECT DISTINCT squad_id FROM clan_role_squads WHERE role_id IN (${drawRoleIds.map(() => '?').join(', ')})
           ORDER BY squad_id`,
        )
        .all(...drawRoleIds)
        .map((r) => r.squad_id)
      : [];
  }
  return { clanId: m.clan_id, userId, isOwner: false, perms, top, drawSquads };
}

const has = (ctx, name) => Boolean(ctx) && (ctx.perms & PERMS[name]) !== 0;

// A role is manageable when it sits strictly below the actor's highest role.
const roleBelow = (ctx, role) => ctx.isOwner || role.position < ctx.top;

// Nobody acts on the owner; others only on members whose highest role is lower than theirs.
function outranks(ctx, target) {
  if (target.isOwner) return false;
  return ctx.isOwner || target.top < ctx.top;
}

// Only flags the actor holds may be switched on or off, so nobody hands out (or strips) power they lack.
function permChangeAllowed(ctx, oldMask, newMask) {
  return ctx.isOwner || ((oldMask ^ newMask) & ~ctx.perms) === 0;
}

function drawScopeAllowed(ctx, drawAll, squadIds) {
  if (ctx.isOwner) return true;
  if (!has(ctx, 'tactics_draw')) return false;
  if (ctx.drawSquads === 'all') return true;
  if (drawAll) return false;
  return squadIds.every((id) => ctx.drawSquads.includes(id));
}

module.exports = {
  PERMS,
  PERM_NAMES,
  ALL_PERMS,
  EVERYONE_DEFAULT,
  permsToNames,
  namesToPerms,
  memberContext,
  has,
  roleBelow,
  outranks,
  permChangeAllowed,
  drawScopeAllowed,
};
```

```js
'use strict';

const { namesToPerms } = require('./clan-permissions');

const COLOR_RE = /^#[0-9a-fA-F]{6}$/;
const TAG_RE = /^[0-9A-Za-zА-Яа-яЁё]{2,5}$/;
const CONTROL_RE = /[\u0000-\u001f\u007f]/;

const ok = (value) => ({ ok: true, value });
const fail = (error) => ({ ok: false, error });

// Case- and ё-insensitive key for unique tags and names (SQLite lower() folds ASCII only).
function clanKey(s) {
  return String(s).trim().toLocaleLowerCase('ru').replace(/ё/g, 'е');
}

function shortText(value, min, max) {
  if (typeof value !== 'string' || CONTROL_RE.test(value)) return null;
  const t = value.trim().replace(/\s+/g, ' ');
  return t.length >= min && t.length <= max ? t : null;
}

function validateClan(input, { create = false } = {}) {
  const out = {};
  if (create || 'tag' in input) {
    if (typeof input.tag !== 'string' || !TAG_RE.test(input.tag.trim())) return fail('tag_invalid');
    out.tag = input.tag.trim();
  }
  if (create || 'name' in input) {
    const name = shortText(input.name, 3, 40);
    if (name === null) return fail('name_invalid');
    out.name = name;
  }
  if ('description' in input) {
    if (typeof input.description !== 'string' || input.description.length > 500) return fail('description_invalid');
    out.description = input.description.trim();
  }
  return ok(out);
}

function validateIdList(value, max) {
  if (!Array.isArray(value) || value.length > max
    || value.some((x) => !Number.isInteger(x) || x < 1) || new Set(value).size !== value.length) {
    return fail('ids must be a list of unique positive integers');
  }
  return ok(value.slice());
}

function validateColor(input, out) {
  if (!('color' in input)) return null;
  if (typeof input.color !== 'string' || !COLOR_RE.test(input.color)) return fail('color must be #rrggbb');
  out.color = input.color;
  return null;
}

function validateRole(input, { create = false } = {}) {
  const out = {};
  if (create || 'name' in input) {
    const name = shortText(input.name, 1, 30);
    if (name === null) return fail('name_invalid');
    out.name = name;
  }
  const colorErr = validateColor(input, out);
  if (colorErr) return colorErr;
  if ('perms' in input) {
    const mask = namesToPerms(input.perms);
    if (mask === null) return fail('unknown permission');
    out.perms = mask;
  }
  if ('draw_all_squads' in input) {
    if (typeof input.draw_all_squads !== 'boolean') return fail('draw_all_squads must be boolean');
    out.draw_all_squads = input.draw_all_squads ? 1 : 0;
  }
  if ('squads' in input) {
    const r = validateIdList(input.squads, 10);
    if (!r.ok) return r;
    out.squads = r.value;
  }
  return ok(out);
}

function validateSquad(input, { create = false } = {}) {
  const out = {};
  if (create || 'name' in input) {
    const name = shortText(input.name, 1, 30);
    if (name === null) return fail('name_invalid');
    out.name = name;
  }
  const colorErr = validateColor(input, out);
  if (colorErr) return colorErr;
  return ok(out);
}

function validateInviteOptions(input) {
  const ttl = 'ttl' in input ? input.ttl : '7d';
  if (ttl !== null && ttl !== '1d' && ttl !== '7d') return fail('ttl must be 1d, 7d or null');
  const maxUses = 'maxUses' in input ? input.maxUses : null;
  if (maxUses !== null && (!Number.isInteger(maxUses) || maxUses < 1 || maxUses > 100)) {
    return fail('maxUses must be null or 1..100');
  }
  return ok({ ttl, maxUses });
}

module.exports = { clanKey, validateClan, validateRole, validateSquad, validateIdList, validateInviteOptions };
```

```js
function tx(db, fn) {
  db.exec('BEGIN');
  try {
    const result = fn();
    db.exec('COMMIT');
    return result;
  } catch (err) {
    db.exec('ROLLBACK');
    throw err;
  }
}

function clanOut(r) {
  return {
    id: r.id,
    tag: r.tag,
    name: r.name,
    description: r.description,
    emblem_url: uploadUrl(r.emblem_path),
    created_at: r.created_at,

const getClan = (db, id) => db.prepare('SELECT * FROM clans WHERE id = ?').get(id) || null;
const getClanByTag = (db, tag) => db.prepare('SELECT * FROM clans WHERE tag_key = ?').get(clanKey(tag)) || null;

function keyTaken(db, column, key, exceptId) {
  return Boolean(db.prepare(`SELECT 1 FROM clans WHERE ${column} = ? AND id != ?`).get(key, exceptId || 0));
}

const countMembers = (db, clanId) =>
  db.prepare('SELECT COUNT(*) AS n FROM clan_members WHERE clan_id = ?').get(clanId).n;

// Joining any clan voids every pending invitation of the player (one clan per player).
function addMember(db, clanId, userId) {
  db.prepare('DELETE FROM clan_invitations WHERE user_id = ?').run(userId);
  db.prepare('INSERT INTO clan_members (clan_id, user_id) VALUES (?, ?)').run(clanId, userId);
}

// Roles and squad places of the member go with the row (ON DELETE CASCADE).
function removeMember(db, userId) {
  db.prepare('DELETE FROM clan_members WHERE user_id = ?').run(userId);
}

  return tx(db, () => {
    const id = Number(db.prepare(
      'INSERT INTO clans (tag, tag_key, name, name_key, description, owner_id) VALUES (?, ?, ?, ?, ?, ?)',
    ).run(tag, clanKey(tag), name, clanKey(name), description || '', ownerId).lastInsertRowid);
    db.prepare(
      "INSERT INTO clan_roles (clan_id, name, color, position, perms, is_everyone) VALUES (?, '@everyone', '#9a9a86', 0, ?, 1)",
    ).run(id, EVERYONE_DEFAULT);
    addMember(db, id, ownerId);
    return id;
  });
}

  const like = '%' + clanKey(q || '').replace(/[\\%_]/g, (ch) => '\\' + ch) + '%';
  return db
    .prepare(
      `SELECT c.*, (SELECT COUNT(*) FROM clan_members m WHERE m.clan_id = c.id) AS members
       FROM clans c WHERE c.tag_key LIKE ? ESCAPE '\\' OR c.name_key LIKE ? ESCAPE '\\'
       ORDER BY members DESC, c.name_key LIMIT 100`,
    )
    .all(like, like)
    .map((r) => ({ tag: r.tag, name: r.name, emblem_url: uploadUrl(r.emblem_path), members: r.members }));
}

function publicProfile(db, clan) {
  const owner = db.prepare('SELECT login FROM users WHERE id = ?').get(clan.owner_id);
  const members = db
    .prepare('SELECT u.id, u.login FROM clan_members m JOIN users u ON u.id = m.user_id WHERE m.clan_id = ? ORDER BY lower(u.login)')

    .all(clan.id);

    .prepare(
```

```js
'use strict';

const { HttpError } = require('./http-util');
const { memberContext, has } = require('./clan-permissions');
const clanRepo = require('./clan-repo');

function need(c) {
  if (!c.user) throw new HttpError(401, 'login required');
}

function limitWrites(c) {
  if (!c.limiters.clansWrite.allow('u:' + c.user.id, c.now())) {
    throw new HttpError(429, 'too many requests, try again later');
  }
}

function checked(result) {
  if (!result.ok) throw new HttpError(400, result.error);
  return result.value;
}

function intParam(c, key) {
  const n = Number(c.params[key]);
  if (!Number.isInteger(n) || n < 1) throw new HttpError(404, 'not found');
  return n;
}

// The actor's context in the clan named by the URL. Not a member of that clan → 404,
// so clan ids cannot be probed.
function memberOf(c) {
  need(c);
  const id = intParam(c, 'id');
  const ctx = memberContext(c.db, c.user.id);
  if (!ctx || ctx.clanId !== id) throw new HttpError(404, 'clan not found');
  return ctx;
}

function requirePerm(ctx, name) {
  if (!has(ctx, name)) throw new HttpError(403, 'forbidden');
}

// Settings and deletion: a member with `perm` ('owner' = the owner only) or the site admin for any clan.
function memberOrAdmin(c, perm) {
  need(c);
  const id = intParam(c, 'id');
  const clan = clanRepo.getClan(c.db, id);
  if (!clan) throw new HttpError(404, 'clan not found');
  const ctx = memberContext(c.db, c.user.id);
  const inClan = Boolean(ctx) && ctx.clanId === id;
  if (c.user.role === 'admin') return { clan, ctx: inClan ? ctx : null, admin: true };
  if (!inClan) throw new HttpError(404, 'clan not found');
  if (perm === 'owner' ? !ctx.isOwner : !has(ctx, perm)) throw new HttpError(403, 'forbidden');
  return { clan, ctx, admin: false };
}

// Another member of the actor's clan, by URL param; anyone else is a 404.
function memberTarget(c, ctx, key) {
  const target = memberContext(c.db, intParam(c, key));
  if (!target || target.clanId !== ctx.clanId) throw new HttpError(404, 'member not found');
  return target;
}

module.exports = { need, limitWrites, checked, intParam, memberOf, requirePerm, memberOrAdmin, memberTarget };
```

```js
function uniqueOrThrow(db, fields, exceptId) {
  if (fields.tag !== undefined && clanRepo.keyTaken(db, 'tag_key', clanKey(fields.tag), exceptId)) {
    throw new HttpError(409, 'tag_taken');
  }
  if (fields.name !== undefined && clanRepo.keyTaken(db, 'name_key', clanKey(fields.name), exceptId)) {
    throw new HttpError(409, 'name_taken');
  }
}

    method: 'GET',
    pattern: '/api/clans',

    pattern: '/api/my/clan',

    pattern: '/api/clans/:tag',

      return { body: clanRepo.publicProfile(c.db, clan) };

      // Every check below runs after the last await, so parallel requests cannot both pass them.
      const row = c.db.prepare('SELECT email_verified_at, clans_blocked FROM users WHERE id = ?').get(c.user.id);
      const state = { emailVerified: Boolean(row.email_verified_at), clansBlocked: Boolean(row.clans_blocked) };
      if (!can(c.user, 'clan:create', state)) {

      }
      if (memberContext(c.db, c.user.id)) throw new HttpError(409, 'already_in_clan');
      uniqueOrThrow(c.db, fields, 0);
      clanRepo.createClan(c.db, { ...fields, ownerId: c.user.id });
```

```js
const DAY = 24 * 60 * 60 * 1000;
const TTL_MS = { '1d': DAY, '7d': 7 * DAY };
const TOKEN_RE = /^[0-9a-f]{64}$/;
// A link works while it is not revoked, not expired and has uses left.
const ACTIVE = '(revoked = 0 AND (expires_at IS NULL OR expires_at > ?) AND (max_uses IS NULL OR uses < max_uses))';

function inviteByToken(c) {
  const token = c.params.token;
  const row = TOKEN_RE.test(token)
    ? c.db.prepare(`SELECT * FROM clan_invites WHERE token_hash = ? AND ${ACTIVE}`).get(sha256(token), c.now())
    : null;
  if (!row) throw new HttpError(404, 'invite_invalid');
  return row;
}

// Shared by both ways to join; runs after the last await, right before the insert.
function joinChecks(db, clanId, userId) {
  if (memberContext(db, userId)) throw new HttpError(409, 'already_in_clan');
  if (clanRepo.countMembers(db, clanId) >= clanRepo.LIMITS.members) throw new HttpError(409, 'clan_full');
}

function listInvites(c, clanId) {
  return c.db
    .prepare(
      `SELECT i.id, u.login AS created_by, i.created_at, i.expires_at, i.max_uses, i.uses
       FROM clan_invites i LEFT JOIN users u ON u.id = i.created_by
       WHERE i.clan_id = ? AND ${ACTIVE} ORDER BY i.id DESC`,
    )
    .all(clanId, c.now());
}

function listInvitations(db, clanId) {
  return db
    .prepare(
      `SELECT i.id, u.login, b.login AS invited_by, i.created_at FROM clan_invitations i
       JOIN users u ON u.id = i.user_id LEFT JOIN users b ON b.id = i.invited_by
       WHERE i.clan_id = ? ORDER BY i.id DESC`,
    )
    .all(clanId);
}

  requirePerm(ctx, 'invite');
  return ctx;
```

```js
(function () {
  'use strict';

  var C = window.Clan;
  var h = C.h;
  var api = C.api;

  function checkboxList(items, checkedIds, enabled) {
    var boxes = [];
    var el = h('div', { class: 'checks' }, items.map(function (it) {
      var cb = h('input', { type: 'checkbox', checked: checkedIds.indexOf(it.id) >= 0, disabled: !enabled(it) });
      boxes.push({ id: it.id, cb: cb });
      return h('label', null, cb, C.chip(it.name, it.color));
    }));
    return {
      el: el,
      value: function () { return boxes.filter(function (b) { return b.cb.checked; }).map(function (b) { return b.id; }); },
    };
  }
  C.checkboxList = checkboxList;

  C.tabs.members = function (el) {
    var d = C.data;
    var err = h('p', { class: 'err', role: 'alert' });
    var list = h('ul', { class: 'list' });

    function openEditor(row, m, editRoles, editSquads) {
      var old = row.querySelector('.editor');
      if (old) { old.remove(); return; }
      var box = h('div', { class: 'editor' });
      var roles = null;
      var squads = null;
      if (editRoles) {
        var assignable = d.roles.filter(function (r) { return !r.everyone; });
        roles = checkboxList(assignable, m.roles, function (r) { return C.roleBelow(r) && C.permsHeld(r.perms); });
        box.appendChild(h('div', { class: 'muted' }, 'Роли'));
        box.appendChild(assignable.length ? roles.el : h('p', { class: 'muted' }, 'Ролей пока нет.'));
      }
      if (editSquads) {
        squads = checkboxList(d.squads, m.squads, function () { return true; });
        box.appendChild(h('div', { class: 'muted' }, 'Отряды'));
        box.appendChild(d.squads.length ? squads.el : h('p', { class: 'muted' }, 'Отрядов пока нет.'));
      }
      var e = h('p', { class: 'err', role: 'alert' });
      var save = h('button', { type: 'button', class: 'primary small' }, 'Сохранить');
      save.addEventListener('click', function () {
        var payload = {};
        if (roles) payload.roles = roles.value();
        if (squads) payload.squads = squads.value();
        C.act(save, e, function () { return api.put(C.base() + '/members/' + m.id, payload).then(C.set); });
      });
      box.appendChild(e);
      box.appendChild(h('div', { class: 'row' }, save,
        h('button', { type: 'button', class: 'small', onclick: function () { box.remove(); } }, 'Отмена')));
      row.appendChild(box);
    }

    d.members.forEach(function (m) {
      var self = m.id === d.me.id;
      var editRoles = C.can('roles_manage') && (self || C.outranks(m));
      var editSquads = C.can('squads_manage') && (self || C.outranks(m));
      var canKick = C.can('kick') && !self && C.outranks(m);
      var row = h('li', null,
        h('span', { class: 'grow' }, m.owner ? '★ ' : '', h('strong', null, m.login), self ? h('span', { class: 'muted' }, ' (вы)') : null),
        m.roles.map(function (id) { var r = C.roleById(id); return r ? C.chip(r.name, r.color) : null; }),
        m.squads.map(function (id) { var s = C.squadById(id); return s ? C.chip(s.name, s.color) : null; }));
      if (editRoles || editSquads) {
        row.appendChild(h('button', { type: 'button', class: 'small', onclick: function () { openEditor(row, m, editRoles, editSquads); } }, 'Изменить'));
      }
      if (canKick) {
        var kick = h('button', { type: 'button', class: 'small danger' }, 'Исключить');
        kick.addEventListener('click', function () {
          if (!window.confirm('Исключить ' + m.login + ' из клана?')) return;
          C.act(kick, err, function () { return api.del(C.base() + '/members/' + m.id).then(C.set); });
        });
        row.appendChild(kick);
      }
      list.appendChild(row);
    });
    el.appendChild(h('p', { class: 'muted' }, 'Участников: ' + d.members.length + ' из ' + d.limits.members + '. ★ — лидер.'));
    el.appendChild(err);
    el.appendChild(list);
```

```js
(function () {
  'use strict';

  var C = window.Clan;
  var h = C.h;
  var api = C.api;

  var PERM_LABELS = [
    ['tactics_view', 'Видеть тактику'],
    ['tactics_draw', 'Рисовать на тактике'],
    ['plans_manage', 'Управлять планами'],
    ['squads_manage', 'Управлять отрядами'],
    ['invite', 'Приглашать'],
    ['kick', 'Исключать'],
    ['roles_manage', 'Управлять ролями'],
    ['clan_settings', 'Настройки клана'],
  ];
  C.PERM_LABELS = PERM_LABELS;

  function swap(ids, i, j) {
    var copy = ids.slice();
    var t = copy[i];
    copy[i] = copy[j];
    copy[j] = t;
    return copy;
  }

  function moveButtons(ids, i, url, err) {
    function go(j) {
      api.put(url, { ids: swap(ids, i, j) }).then(C.set).catch(function (ex) { err.textContent = C.errorText(ex); });
    }
    return [
      h('button', { type: 'button', class: 'small', 'aria-label': 'Выше', disabled: i <= 0, onclick: function () { go(i - 1); } }, '↑'),
      h('button', { type: 'button', class: 'small', 'aria-label': 'Ниже', disabled: i >= ids.length - 1, onclick: function () { go(i + 1); } }, '↓'),
    ];
  }

  function roleEditor(r, onDone) {
    var d = C.data;
    var me = d.me;
    var name = C.field('Название', { type: 'text', maxLength: 30, value: r ? r.name : '', disabled: Boolean(r && r.everyone) });
    var color = h('input', { type: 'color', value: r ? r.color : '#9a9a86', 'aria-label': 'Цвет' });
    var perms = PERM_LABELS.map(function (p) {
      var cb = h('input', { type: 'checkbox', checked: Boolean(r && r.perms.indexOf(p[0]) >= 0), disabled: !(me.isOwner || C.can(p[0])) });
      return { name: p[0], cb: cb, el: h('label', null, cb, p[1]) };
    });
    var canScope = me.isOwner || C.can('tactics_draw');
    var allAllowed = me.isOwner || me.drawSquads === 'all';
    var scopeName = 'scope-' + (r ? r.id : 'new');
    var all = h('input', { type: 'radio', name: scopeName, checked: Boolean(r && r.draw_all_squads), disabled: !canScope || !allAllowed });
    var some = h('input', { type: 'radio', name: scopeName, checked: !(r && r.draw_all_squads), disabled: !canScope });
    var squads = C.checkboxList(d.squads, r ? r.squads : [], function (s) {
      return canScope && (allAllowed || me.drawSquads.indexOf(s.id) >= 0);
    });
    var err = h('p', { class: 'err', role: 'alert' });
    var save = h('button', { type: 'button', class: 'primary small' }, r ? 'Сохранить' : 'Создать');
    save.addEventListener('click', function () {
      var payload = {
        color: color.value,
        perms: perms.filter(function (p) { return p.cb.checked; }).map(function (p) { return p.name; }),
      };
      if (!r || !r.everyone) payload.name = name.input.value;
      // The draw scope is sent only by those who may change it; the server skips the check when it is unchanged.
      if (canScope) {
        payload.draw_all_squads = all.checked;
        if (!all.checked) payload.squads = squads.value();
      }
      C.act(save, err, function () {
        return (r ? api.patch(C.base() + '/roles/' + r.id, payload) : api.post(C.base() + '/roles', payload)).then(C.set);
      });
    });
    return h('div', { class: 'editor' },
      r && r.everyone ? h('p', { class: 'muted' }, 'Права @everyone есть у каждого участника клана.') : name.el,
      h('label', null, 'Цвет ', color),
      h('div', { class: 'muted' }, 'Права'),
      h('div', { class: 'checks' }, perms.map(function (p) { return p.el; })),
      h('div', { class: 'muted' }, 'Рисует для (вместе с правом «Рисовать на тактике»)'),
      h('div', { class: 'checks' }, h('label', null, all, 'все отряды'), h('label', null, some, 'выбранные отряды:')),
      d.squads.length ? squads.el : h('p', { class: 'muted' }, 'Отрядов пока нет.'),
      err,
      h('div', { class: 'row' }, save, h('button', { type: 'button', class: 'small', onclick: onDone }, 'Отмена')));

  C.tabs.roles = function (el) {
```

```js
(function () {
  'use strict';

  var C = window.Clan;
  var h = C.h;
  var api = C.api;

  function fmtMs(ms) { return new Date(ms).toLocaleString('ru-RU', { dateStyle: 'short', timeStyle: 'short' }); }

  C.tabs.invites = function (el) {
    var base = C.base();
    var err = h('p', { class: 'err', role: 'alert' });
    var created = h('div');
    var links = h('ul', { class: 'list' });
    var pending = h('ul', { class: 'list' });

    function renderLinks(data) {
      links.textContent = '';
      if (!data.invites.length) links.appendChild(h('li', { class: 'muted' }, 'Активных ссылок нет.'));
      data.invites.forEach(function (inv) {
        var revoke = h('button', { type: 'button', class: 'small danger' }, 'Отозвать');
        revoke.addEventListener('click', function () {
          C.act(revoke, err, function () { return api.del(base + '/invites/' + inv.id).then(renderLinks); });
        });
        links.appendChild(h('li', null, h('span', { class: 'grow' },
          'Создал ' + (inv.created_by || '—') + ' · ' + (inv.expires_at ? 'до ' + fmtMs(inv.expires_at) : 'бессрочно')
          + ' · использована ' + inv.uses + (inv.max_uses ? ' из ' + inv.max_uses : '')), revoke));
      });
    }

    function renderPending(data) {
      pending.textContent = '';
      if (!data.invitations.length) pending.appendChild(h('li', { class: 'muted' }, 'Ожидающих приглашений нет.'));
      data.invitations.forEach(function (inv) {
        var revoke = h('button', { type: 'button', class: 'small danger' }, 'Отозвать');
        revoke.addEventListener('click', function () {
          C.act(revoke, err, function () { return api.del(base + '/invitations/' + inv.id).then(renderPending); });
        });
        pending.appendChild(h('li', null, h('span', { class: 'grow' }, h('strong', null, inv.login),
          h('span', { class: 'muted' }, ' · пригласил ' + (inv.invited_by || '—'))), revoke));
      });
    }

    var ttl = h('select', { 'aria-label': 'Срок действия' },
      h('option', { value: '1d' }, '1 день'), h('option', { value: '7d', selected: true }, '7 дней'), h('option', { value: '' }, 'Бессрочно'));
    var uses = h('select', { 'aria-label': 'Сколько раз' }, h('option', { value: '' }, 'Без ограничений'),
      [1, 5, 10, 25, 50].map(function (n) { return h('option', { value: String(n) }, n + ' раз'); }));
    var create = h('button', { type: 'button', class: 'primary' }, 'Создать ссылку');
    create.addEventListener('click', function () {
      C.act(create, err, function () {
        return api.post(base + '/invites', { ttl: ttl.value || null, maxUses: uses.value ? Number(uses.value) : null }).then(function (inv) {
          var input = h('input', { type: 'text', readOnly: true, value: inv.url, 'aria-label': 'Ссылка-приглашение' });
          var copy = h('button', { type: 'button' }, 'Копировать');
          copy.addEventListener('click', function () {
            input.select();
            var done = function () { copy.textContent = 'Скопировано'; };
            if (navigator.clipboard) navigator.clipboard.writeText(inv.url).then(done, function () { document.execCommand('copy'); done(); });
            else { document.execCommand('copy'); done(); }
          });
          created.textContent = '';
          created.appendChild(h('p', { class: 'muted' }, 'Ссылка показывается один раз — скопируйте её сейчас.'));
          created.appendChild(h('div', { class: 'copy' }, input, copy));
          return api.get(base + '/invites').then(renderLinks);
        });
      });
    });

    var login = C.field('Логин игрока', { type: 'text', maxLength: 32, required: true, autocomplete: 'off' });
    var form = h('form', null, login.el, h('button', { type: 'submit', class: 'primary' }, 'Пригласить'));
    C.bind(form, err, function () {
      return api.post(base + '/invitations', { login: login.input.value }).then(function (data) {
        login.input.value = '';
        renderPending(data);
      });
    });

    el.appendChild(err);
    el.appendChild(h('h2', null, 'Ссылка-приглашение'));
    el.appendChild(h('div', { class: 'row' }, h('label', null, 'Срок', ttl), h('label', null, 'Использований', uses)));
    el.appendChild(h('div', { class: 'row' }, create));
    el.appendChild(created);
    el.appendChild(links);
    el.appendChild(h('h2', null, 'Пригласить по логину'));
    el.appendChild(h('p', { class: 'muted' }, 'Игрок увидит приглашение на странице «Клан» и примет его сам.'));
    el.appendChild(form);
    el.appendChild(pending);
    api.get(base + '/invites').then(renderLinks).catch(function (ex) { err.textContent = C.errorText(ex); });
    api.get(base + '/invitations').then(renderPending).catch(function (ex) { err.textContent = C.errorText(ex); });
  };

  C.tabs.settings = function (el) {
    var d = C.data;
    var base = C.base();
    var err = h('p', { class: 'err', role: 'alert' });
    el.appendChild(err);

    if (C.can('clan_settings')) {
      var tag = C.field('Тег', { type: 'text', maxLength: 5, value: d.clan.tag, required: true });
      var name = C.field('Название', { type: 'text', maxLength: 40, value: d.clan.name, required: true });
      var desc = h('textarea', { maxLength: 500, rows: 4, value: d.clan.description });
      var form = h('form', null, tag.el, name.el, h('label', null, 'Описание', desc), h('button', { type: 'submit', class: 'primary' }, 'Сохранить'));
      C.bind(form, err, function () {
        return api.patch(base, { tag: tag.input.value, name: name.input.value, description: desc.value }).then(C.set);
      });
      var file = h('input', { type: 'file', accept: 'image/png,image/jpeg,image/webp', 'aria-label': 'Файл эмблемы' });
      file.addEventListener('change', function () {
        var f = file.files[0];
        if (!f) return;
        if (f.size > 200 * 1024) { err.textContent = 'Файл больше 200 КБ.'; file.value = ''; return; }
        err.textContent = '';
        api.upload('PUT', base + '/emblem', f).then(C.set).catch(function (ex) { err.textContent = C.errorText(ex); file.value = ''; });
      });
      el.appendChild(h('h2', null, 'Клан'));
      el.appendChild(form);
      el.appendChild(h('h2', null, 'Эмблема'));
      el.appendChild(h('p', { class: 'muted' }, 'PNG, JPEG или WebP, до 200 КБ и 1024×1024.'));
      el.appendChild(file);
      if (d.clan.emblem_url) {
        var drop = h('button', { type: 'button', class: 'small' }, 'Убрать эмблему');
        drop.addEventListener('click', function () { C.act(drop, err, function () { return api.del(base + '/emblem').then(C.set); }); });
        el.appendChild(h('div', { class: 'row' }, drop));
      }
    }

    if (d.me.isOwner) {
      var others = d.members.filter(function (m) { return m.id !== d.me.id; });
      var who = h('select', { 'aria-label': 'Новый лидер' }, others.map(function (m) { return h('option', { value: String(m.id) }, m.login); }));
      var transfer = h('button', { type: 'button', disabled: !others.length }, 'Передать лидерство');
      transfer.addEventListener('click', function () {
        var target = others.filter(function (m) { return String(m.id) === who.value; })[0];
        if (!target || !window.confirm('Передать лидерство игроку ' + target.login + '? Вернуть его сможет только новый лидер.')) return;
        C.act(transfer, err, function () { return api.post(base + '/transfer', { userId: target.id }).then(C.set); });
      });
      var confirmTag = C.field('Введите тег клана, чтобы подтвердить удаление', { type: 'text', autocomplete: 'off' });
      var del = h('button', { type: 'button', class: 'danger', disabled: true }, 'Удалить клан');
      confirmTag.input.addEventListener('input', function () { del.disabled = confirmTag.input.value.trim() !== d.clan.tag; });
      del.addEventListener('click', function () { C.act(del, err, function () { return api.del(base).then(C.set); }); });
      el.appendChild(h('h2', null, 'Лидерство'));
      el.appendChild(others.length ? who : h('p', { class: 'muted' }, 'В клане пока никого, кроме вас.'));
      el.appendChild(h('div', { class: 'row' }, transfer));
      el.appendChild(h('h2', null, 'Удаление клана'));
      el.appendChild(h('p', { class: 'muted' }, 'Удаляются роли, отряды и приглашения. Отменить нельзя.'));
      el.appendChild(confirmTag.el);
      el.appendChild(h('div', { class: 'row' }, del));
    }
  };
})();
```
